# Security Policy

We take the security of our platform, services, and users seriously. This document outlines how to report security issues and the versions we actively support.

## Supported Versions

We actively maintain and provide security patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not** open a public issue. Doing so risks exposing the vulnerability to malicious actors before a patch is available.

Instead, please report the vulnerability by emailing **security@vendex.com** (or contact the repository maintainers directly). 

Please include the following details in your report:
* A description of the vulnerability and its potential impact.
* Detailed steps to reproduce the issue (proof-of-concept scripts or API requests).
* Any potential mitigation steps or patch suggestions.

We will review your submission and respond within 48 hours to coordinate a security release.

## Our Commitment

For any validated vulnerability report, we commit to:
* Acknowledging receipt of the report promptly.
* Working diligently to develop and test a security patch.
* Giving appropriate credit to the reporter in our release notes (if desired).
* Releasing a patched version as soon as possible.
